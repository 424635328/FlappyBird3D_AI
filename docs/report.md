# 项目汇报提纲（10 分钟）

可直接复用的讲解稿结构：每节标注时长与要展示的画面，讲完即换下一节。

## 0. 目标与边界（30 秒）

> 这个项目做两件事：把 Flappy Bird 从 2D 做成 3D；然后用强化学习训练一个能自己玩的智能体。
>
> 关键约束：环境是随机的——管道速度、生成间隔、上下位置、缝隙大小、小鸟出生状态每回合都不同。所以目标不是"记住一条通关路线"，而是"学会一套能适应变化的策略"。

**画面**：Unity 菜单 → 选择 AI 模式。

## 1. 演示（2 分钟）

- 手动模式先玩 10 秒：空格振翅、`LeftShift` 加速下落，展示物理手感。
- 切到 AI 模式，连续看 3–5 个回合：
  - 指出**每回合管道速度不同**（观察管道左移速度）；
  - 指出**缝隙与高度在变**；
  - 指出**小鸟出生瞬间的位置/初速度有细微差异**。
- 强调结论：环境在变，策略不变——这才是训练出来的泛化能力。

## 2. 技术拆解（4 分钟）

### 2.1 架构（1 分钟）

| 层 | 组成 |
| --- | --- |
| 游戏层 | `GameManager`（分数/难度/单例）、`PipeSpawner`（生成与随机化）、`PipeMovement`（移动与回收）、`ScoreTrigger`（过管判定） |
| 智能体层 | `FlappyAgent`：12 维观测、3 个离散动作、4 项奖励 |
| 训练层 | `mlagents-learn`（PPO）+ `config/flappybird_config.yaml` |
| 推理层 | 导出的 ONNX 接入 `Behavior Parameters`，`Inference Only` 模式运行 |

### 2.2 观测设计（1 分钟）

12 维：自身竖直速度、竖直位置；前方最近 3 组管道的「缝隙中心相对高度 / 水平距离 / 缝隙高度」；当前管道速度。

> 为什么是 3 组管道而不是 1 组：只看最近一组时，策略无法为"下一组"提前调整；加入第 2、3 组后，学习速度和稳定性都有明显改善。

### 2.3 奖励设计（1 分钟）

| 事件 | 值 | 设计意图 |
| --- | --- | --- |
| 存活 | `+0.15` | 鼓励延长存活，但不足以抵消撞管惩罚 |
| 过管 | `+0.20` | 提供明确的前进信号 |
| 撞管 | `-1.0` | 主要负反馈 |
| 出界 | `-2.0` | 比撞管更重，避免"飞出屏幕换安全"的退化策略 |

### 2.4 随机化（1 分钟）

五个维度、三个落点：`GameManager`（每回合速度）、`PipeSpawner`（间隔/高度/缝隙）、`FlappyAgent.OnEpisodeBegin`（出生位置与初速度）。

> 随机化是双刃剑：范围太小学不到泛化，范围太大前期学不动。当前配置采用中间范围，并通过课程学习可以进一步扩展。

## 3. 工程改进（2 分钟）

- 依赖改为 UPM registry（`com.unity.ml-agents@3.0.0`），不再把第三方源码拷进仓库；
- Build Settings 修正为 `MainMenuScene → GameScene`，避免构建后无入口场景；
- 背景音乐 WAV → OGG，仓库体积从 221 MB 降到 22 MB；
- 训练配置、文档、自检脚本与 CI 一并入库，任何人克隆后可按文档复现。

## 4. 收获与反思（1 分钟）

- 强化学习的瓶颈通常不在算法，而在**观测是否携带足够信息**、**奖励是否与目标一致**；
- 随机化提升泛化的前提是"可学"：先窄后宽的课程式随机比一次性放开更稳；
- 工程规范（依赖、配置、文档、自检）决定了项目能不能被别人接续，而不是能不能跑一次。

## 5. 展望（30 秒）

对抗训练（管道 Agent 与小鸟博弈）、视觉输入（CNN 直接看画面）、课程学习与对象池优化。详见 [roadmap.md](roadmap.md)。

## 附：常见提问预案

| 提问 | 回答要点 |
| --- | --- |
| 为什么用 PPO 而不是 DQN/SAC | 离散动作 + 高随机环境，PPO 的裁剪更新更稳；SAC 更适合连续动作，可作为连续跳跃的下一步 |
| 训练了多久 | 以步数为准（上限 1500 万步），实际耗时取决于 CPU 核数与并行环境数 |
| 怎么证明不是背板 | 每回合环境参数不同，且关掉/更换管道布局后策略仍能通过 |
| 随机化会不会让 AI 学不会 | 会，所以需要控制范围与引入课程学习；这就是本项目的主要调参工作 |
| 能不能直接看画面 | 可以，改用 `CameraSensorComponent`，代价是训练成本显著上升 |
